# DR-002 — Fahrenheit presentation and BAR decimal glyph

- Status: resolved 2026-08-15 by Marcos's direct design instruction
- Scope: Sprint 6 settings and value typography only

## Request

Add a persistent °C/°F choice without changing the canonical Celsius state,
color, bar, or alarm logic. In Fahrenheit, show the 50 °C lower display floor as
`<122`, the unit as `°F`, and convert the two temperature reference labels.

Repair the one-decimal BAR value so its separator is drawn by the same 96 px
Montserrat numeric font and does not appear as LVGL's missing-glyph rectangle.

## Resolution

Approved directly by Marcos on 2026-08-15. D-045 is the binding implementation
decision. No other driving-screen geometry or behavior changes.
